# McDMonopoly

An unofficial fan simulator of the McDonald's Canada 2026 **Monopoly Golden Edition** gold peel stickers. Pick an item, pull it into view, peel each sticker off with your mouse or finger, and watch the Monopoly board fill in.

> Fan project. Not affiliated with, endorsed by, or sponsored by McDonald's or Hasbro. MONOPOLY and McDonald's are trademarks of their respective owners. Non-commercial; no real prizes.

## Running it

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc -b && vite build -> dist/
npm run preview    # serve the built app
npm run typecheck
npm run lint       # oxlint
npm test           # vitest (engine + peel math)
npm run data       # regenerate src/data/*.json from the source odds file
```

Node 20+ is required. Progress is saved in `localStorage` under the key `mcdmonopoly:v1`.

### URL options

| Option | Where | Effect |
| --- | --- | --- |
| `?seed=N` | any page | Uses a seeded RNG (mulberry32), so draws repeat exactly. Handy for testing. |
| `?debug=1` | `/board` | Outlines every board hotspot with its stamp number. |
| `?place=1` | `/item/:id` | Turns on the sticker placement helper (see below). |

### Pages

- `/`: the item carousel (scroll, drag, arrow keys, or the prev and next buttons), then **Pull**.
- `/item/:id`: the peel view. Grab a sticker near its edge and drag.
- `/board`: the board with collected spaces lit up, X/28 and set progress, **Share my board** (PNG), and **Reset** (asks you to confirm first).
- `/prizes`: every prize with its published odds and your chance in the current mode.
- `/peel-lab`: one sticker plus sliders for every value in `src/peel/peelConfig.ts`. It prints a snippet of the values you changed so you can paste them back into the config.

## Data

| File | Source | Edit by hand? |
| --- | --- | --- |
| `docs/prizes-and-odds.source.json` | Supplied odds and prize list | Yes: this is the source of truth |
| `src/data/properties.json` | Generated by `npm run data` | No |
| `src/data/prizes.json` | Generated by `npm run data` | No |
| `src/data/odds.json` | Generated, includes the Fun and Realistic mode parameters | No (change the parameters in `scripts/build-data.ts`) |
| `src/data/boardSpaces.json` | Measured once from the board scan | Only if the board image changes |
| `src/data/items.json` | Hand-written | Yes |

After you edit the source JSON, run `npm run data`. When the app starts, it checks all the data (`src/engine/validate.ts`). If anything is wrong (for example, a set references a missing stamp or a board space has no property), it shows an error screen listing the problems instead of the app.

### Replacing the placeholder items

The six items in `public/assets/items/*.svg` are clearly labelled placeholders. To swap in a real scan:

1. Put the image in `public/assets/items/`. Use a square PNG or JPG, ideally 1000 px or larger, and crop it tightly.
2. In `src/data/items.json`, point `image` at the new file and set `"placeholder": false`.
3. Open `/item/<id>?place=1`. Click where each sticker should sit; the helper logs normalized `x`/`y` and copies a ready-made `stickers` array to the clipboard. Adjust `size` (a fraction of the item width) and `rotation` (degrees) by hand.
4. `stock` sets how many times an item can be pulled. `null` means unlimited. Stock is used up when you press **Pull**, not when you peel.

## How the draw works

Every sticker gives you **one stamp** (#801–#828). It can also carry an **instant-win prize**. Both are decided when you first grab the sticker, and committed only when the sticker actually tears off. If you let go early, it springs back and nothing is recorded.

**Stamps.** Each Collect-to-Win set has one rare stamp, taken from the odds file. A rare stamp's weight is `(1 / oddsOneIn) ^ rareExponent`. The common stamps split the remaining probability equally.

**Instant wins.** Only the 39 prizes that come on the game piece can be drawn. Digital Bonus Play and the Golden Prize Draw are shown in the prize guide for information only.

| Mode | Rare stamps | Instant wins | Prize pools |
| --- | --- | --- | --- |
| **Fun** (default) | `rareExponent 0.3` makes rare stamps uncommon but actually findable | Total hit chance of 45%, split by `(1/odds)^0.35` | Ignored |
| **Realistic** | Published odds (`rareExponent 1`) | Each prize at its published `1/odds` | Count down. When a pool reaches 0, that prize can't be won again |

The RNG is behind a small interface (`src/engine/rng.ts`). `setRng()` swaps it out, and that's how `?seed=` and the tests work.

**Collection rules.** A stamp you already own is a duplicate: it's shown as "Duplicate" and discarded automatically. A set is completed the first time you own all of its stamps, and is counted only once. Instant wins pile up in your history.

## The peel

All of the peel code lives in `src/peel/`:

- `curl.ts` holds the geometry, as pure functions with unit tests. A subdivided plane is wrapped around a cylinder at a fold line. The fold line is placed so that the point you grabbed stays under your pointer.
- `peelController.ts` is the state machine. Its phases are idle, dragging, spring-back, detaching, flying and gone. It applies spring smoothing to the pointer, and the smoothed pointer speed sets the curl radius and the flutter. Slow drags give a tight curl; fast drags give a loose, wobbly one. The sticker tears off once more than 60% of it is lifted, or when you fling it fast enough.
- `PeelScene.ts` is the Three.js scene. The sticker's front is metallic gold; its back is grey-silver with mirrored "see rules" text. It casts a soft shadow onto the item, and a shimmer plays over the card it reveals.
- `sound.ts` synthesizes all sounds with WebAudio (peel noise, pop, chime), so there are no audio files. The header has a mute toggle.
- If you've turned on reduced motion, the sticker fades out instead of curling.

## Decisions

- **Stamp numbering.** In the HTML list I was given, #806–#811 are in a different order and "Columbia Icefield" is included. The board scan (PDF page 2) and the odds JSON agree with each other, so I followed them: 806 Percé Rock, 807 Miles Canyon, 808 Lunenburg Harbour, 809 Signal Hill, 810 Peggys Cove, 811 Tunnels of Moose Jaw. Columbia Icefield isn't on the board, so it isn't included. The group names ("Airports / Transportation", "Highways / Utilities") come from the HTML.
- **Revealed card design.** The card is plain white with the property name and number, a "REQ." line listing the stamps the set needs, and the set's prize. A thin bar in the group colour runs along the top. Instant wins add a red banner.
- **Rare stamps are unofficial.** McDonald's doesn't publish which stamp is rare. The ones used here come from the odds file and always appear with that caveat.
- **Fun mode is the default.** At the real odds, the large prizes are effectively impossible to win. Realistic mode is still there for anyone who wants it.
- **Pulling outward curls the sticker instead of flipping it.** Dragging away from the sticker lifts and curls the edge, with the fold angle capped at `maxFoldAngle`. This avoids an unnatural full flip.
- **Touch is more forgiving.** On a touchscreen the grab zone around the sticker edge is about 35% larger. If you press the middle of a sticker instead of its edge, it nudges and shows a hint.
- **Reload requires a new Pull.** The peel view only opens from **Pull**, so reloading `/item/:id` can't be used to re-roll stock.
- **Shared board PNG.** It's drawn on a canvas from the board scan. Spaces you don't have are greyed out and the ones you do have get a gold outline, so it works without a screenshot library.
